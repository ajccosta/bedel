    Everything above is public, read without a token. Changing the course takes a token from an owner of , made for this course alone.

    How this token works

    • It reaches and nothing else. It's a fine-grained token made for . Classic tokens are refused, and the page proves the token belongs to before using it.
    • It goes only to GitHub. It stays in this tab's memory and is sent only to api.github.com. The page's Content-Security-Policy stops your browser from letting it connect anywhere else. Closing the tab forgets it.
    • This page is your course's own copy. It's published from 's web/ folder, and changes only when you pull bedel's updates.
    • Make it last as long as you need it. A week is plenty for a round of changes. Make another next time.
